## Maintaining this collection

Use the smoothie recipe template in `templates/smoothie-recipe.md` to create a
version under this folder. Give it a descriptive or dated name and select
`current`, `experimental`, or `historical`. Maintain quantities in the recipe's
ingredient table; keep shared product facts and measured conversions in ingredient
notes. Preserve aliases when renaming notes. Select a new current recipe explicitly
and mark the previous one historical when it is replaced.

Native Bases show the same properties in Obsidian and Quartz. Website results
update on rebuild. Nutrition totals, costs, and shopping lists remain manual until
quantities and sources are consistent.

## Notes

- Originally I was using a lot of frozen vegetables but then I noticed that one was supposed to cook them fully before using them. I tried this a bit and found it to be a significant inconvenience, so I've been moving to using fresh vegetables that are marked as "ready to eat", it costs more and I'll evaluate over time whether the reduced time/energy is worth the increased cost.
